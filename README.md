# Подбор автозапчастей

React + Redux Toolkit + Bootstrap, собирается и тестируется через [Bun](https://bun.sh). Работает с API "Проценка" (документация - `wsprice.pdf`).

1. Вводим артикул - получаем список производителей.
2. Выбираем производителя - получаем таблицу аналогов и предложений (цена и остаток по каждому складу).

## Запуск

```bash
bun install
bun dev         # http://localhost:3000
bun test        # тесты
bun lint        # линтер (oxlint)
bun format      # форматирование (oxfmt)
bun run build   # сборка в dist/
```

Используется демо-ключ из документации. Свой ключ - константа `API_KEY` в `src/api.js`.

## Что где лежит

```
src/
  api.js                  запросы к API и разбор ответа
  searchSlice.js          Redux: состояние обоих запросов (загрузка / данные / ошибка)
  store.js                Redux store
  App.jsx                 страница
  components/
    SearchForm.jsx        этап 1: ввод артикула
    BrandList.jsx         этап 1: список производителей
    OffersTable.jsx       этап 2: таблица аналогов и предложений
    RequestStatus.jsx     лоадер / ошибка / "ничего не найдено"
    Loader.jsx            спиннер
```

## Заметки

- Цена берётся со склада, а не из общего поля `price` товара: так требует документация. Поэтому у одной детали может быть несколько строк - по строке на склад.
- API работает только по `http`. Если выложить приложение на `https`-хостинг, браузер заблокирует запросы - понадобится прокси.
